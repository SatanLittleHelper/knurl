# Knurl — Design Spec

## Overview

Knurl — мобильное приложение-дневник тренировок для iOS и Android. Позволяет планировать тренировки и логировать подходы. Личное приложение без социальных функций.

## Tech Stack

- **Mobile:** Flutter (Dart), iOS + Android
- **Backend:** Go + PostgreSQL
- **Repo:** Монорепа (`mobile/` + `backend/`)

## Architecture

```
Flutter App
├── Local SQLite (drift)     ← основное хранилище
├── Sync Engine              ← фоновая синхронизация
└── Go API Client

Go Backend
├── REST API
├── Auth (JWT)
└── PostgreSQL
```

Приложение всегда читает и пишет в локальный SQLite. Sync Engine отправляет изменения на Go-сервер при наличии сети. Конфликты решаются по принципу "последняя запись побеждает" (v1).

## Data Model

- `Exercise` — упражнение из внешнего API (кэшируется локально)
- `WorkoutPlan` — программа тренировок (например "Сплит 3 дня")
- `WorkoutDay` — день плана: набор упражнений с целевыми весами и повторениями
- `WorkoutSession` — конкретная тренировка (дата, ссылка на план)
- `SetLog` — залогированный подход (упражнение, вес, повторения)

Каждая запись имеет `updated_at` и `synced` флаг для синхронизации.

## Screens

### Auth
- Регистрация и вход по email + паролю
- После входа — полная загрузка данных с сервера

### Home
- Тренировка на сегодня (если назначена по плану) с кнопкой "Начать"
- Последние 3 сессии

### Planner
- Список планов тренировок
- Создание и редактирование плана: название, дни, упражнения, целевые веса и повторения

### Active Workout
- Список упражнений из плана
- По каждому упражнению: подходы с полями вес / повторения, кнопка "Готово"
- Таймер отдыха между подходами
- Возможность добавить упражнение вне плана

### History
- Список прошлых сессий по дате
- Детали сессии: упражнения, веса, повторения

### Exercise Library
- Упражнения из внешнего публичного API (провайдер выбирается на этапе реализации: ExerciseDB, Wger, API Ninjas)
- Кэшируются локально в SQLite для офлайн-доступа
- Фильтр по группе мышц
- Пользователь не может добавлять или редактировать упражнения

## Auth & Sync

**Авторизация:**
- Email + пароль, JWT + refresh token
- Автоматическое обновление сессии

**Синхронизация:**
- Sync Engine работает фоново, не блокирует UI
- При появлении сети отправляет все записи с `synced = false`
- Сервер возвращает изменения с других устройств

## Backend

- REST API: стандартные CRUD эндпоинты
- PostgreSQL как основная БД
- Справочник упражнений управляется через прямой SQL (без UI в v1)

## Out of Scope (v1)

- Социальные функции
- Графики прогресса и личные рекорды
- Кастомные упражнения пользователя
- Уведомления
