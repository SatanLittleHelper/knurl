# Задача 6: Упражнения — кэш внешнего API

**Что строим:** `GET /exercises` и `GET /exercises?muscle=chest` — список упражнений из внешнего API с кэшированием в PostgreSQL.

---

## Почему кэш, а не прямые запросы к API

Внешние API имеют лимиты запросов (rate limits) и могут быть временно недоступны. Если кэшировать данные в своей БД:
- Приложение работает даже если внешний API лежит
- Нет лишних запросов к платному API
- Быстро — данные рядом, не нужно ходить в интернет

Кэш обновляется раз в 24 часа — упражнения меняются редко.

---

## Паттерн "интерфейс провайдера"

Конкретный API упражнений ещё не выбран (ExerciseDB, Wger, API Ninjas). Чтобы не переписывать весь код при смене провайдера, используем Go-интерфейс:

```go
type ExerciseProvider interface {
    FetchAll(ctx context.Context) ([]Exercise, error)
}
```

Сейчас создадим `StubProvider` с захардкоженными данными. Когда выберем реальный API — создадим новый тип, реализующий тот же интерфейс, и заменим одну строку в `main.go`.

В TypeScript это похоже на интерфейс с несколькими реализациями.

---

## GORM-модель Exercise

```go
type Exercise struct {
    ID           string `gorm:"primaryKey"` // TEXT в SQL, ID от внешнего API
    ...
}
```

Заметь: `ID` здесь `string`, а не `uuid.UUID` — потому что ID берётся из внешнего API.

package exercises

import "time"

// Exercise — GORM-модель и одновременно тип который возвращает провайдер.
// gorm:"primaryKey" — ID является первичным ключом (TEXT, не UUID)
type Exercise struct {
	ID           string    `gorm:"primaryKey"           json:"id"`
	Name         string    `gorm:"not null"             json:"name"`
	MuscleGroup  string    `gorm:"column:muscle_group;not null" json:"muscle_group"`
	Equipment    string    `                            json:"equipment,omitempty"`
	Instructions string    `                            json:"instructions,omitempty"`
	GifURL       string    `gorm:"column:gif_url"       json:"gif_url,omitempty"`
	CachedAt     time.Time `gorm:"column:cached_at"     json:"-"` // json:"-" — не включать в JSON-ответ
}

// TableName явно задаёт имя таблицы.
// По умолчанию GORM использует snake_case+plural от имени структуры: "exercises" — совпадает.
// Но лучше задать явно для ясности.
func (Exercise) TableName() string {
	return "exercises"
}

- [ ] **Шаг 3: Создать `internal/exercises/service.go`**

```go
package exercises

import (
	"context"
	"time"

	"gorm.io/gorm"
	"gorm.io/gorm/clause"
)

const cacheTTL = 24 * time.Hour

type Service struct {
	db       *gorm.DB
	provider ExerciseProvider
}

func NewService(db *gorm.DB, provider ExerciseProvider) *Service {
	return &Service{db: db, provider: provider}
}

// List возвращает упражнения, опционально фильтруя по группе мышц.
// Обновляет кэш если данные устарели.
func (s *Service) List(_ context.Context, muscle string) ([]Exercise, error) {
	// Проверяем актуальность кэша
	if s.isCacheStale() {
		// Если обновить не удалось — используем то что есть в БД.
		// best-effort: не падаем из-за временной недоступности внешнего API.
		_ = s.refreshCache()
	}

	return s.fromDB(muscle)
}

// isCacheStale проверяет нужно ли обновить кэш.
func (s *Service) isCacheStale() bool {
	var minCachedAt time.Time
	// db.Model(&Exercise{}).Select("MIN(cached_at)").Scan(&minCachedAt)
	// → SELECT MIN(cached_at) FROM exercises
	s.db.Model(&Exercise{}).Select("MIN(cached_at)").Scan(&minCachedAt)
	return minCachedAt.IsZero() || time.Since(minCachedAt) > cacheTTL
}

// refreshCache загружает упражнения из внешнего API и сохраняет в БД.
func (s *Service) refreshCache() error {
	exercises, err := s.provider.FetchAll(context.Background())
	if err != nil {
		return err
	}

	// Обновляем cached_at для всех загруженных упражнений
	now := time.Now()
	for i := range exercises {
		exercises[i].CachedAt = now
	}

	// clause.OnConflict — что делать если запись уже существует (по primary key).
	// UpdateAll: true — обновить все поля.
	// Это аналог SQL: INSERT ... ON CONFLICT DO UPDATE SET ...
	return s.db.Clauses(clause.OnConflict{UpdateAll: true}).Create(&exercises).Error
}

// fromDB читает упражнения из локальной БД.
func (s *Service) fromDB(muscle string) ([]Exercise, error) {
	var exercises []Exercise
	query := s.db.Order("name")

	// Если передан фильтр по группе мышц — добавляем WHERE
	if muscle != "" {
		query = query.Where("muscle_group = ?", muscle)
	}

	result := query.Find(&exercises)
	return exercises, result.Error
}
```

- [ ] **Шаг 4: Создать `internal/exercises/handler.go`**

```go
package exercises

import (
	"encoding/json"
	"net/http"
)

type Handler struct {
	svc *Service
}

func NewHandler(svc *Service) *Handler {
	return &Handler{svc: svc}
}

// List обрабатывает GET /exercises и GET /exercises?muscle=chest
func (h *Handler) List(w http.ResponseWriter, r *http.Request) {
	// r.URL.Query().Get("muscle") — читает query-параметр из URL.
	// Если параметра нет — возвращает пустую строку.
	muscle := r.URL.Query().Get("muscle")

	exercises, err := h.svc.List(r.Context(), muscle)
	if err != nil {
		http.Error(w, "internal error", http.StatusInternalServerError)
		return
	}

	w.Header().Set("Content-Type", "application/json")
	json.NewEncoder(w).Encode(exercises)
}
```
