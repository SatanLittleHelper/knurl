# Задача 8: CRUD сессий тренировок

**Что строим:** Маршруты для управления сессиями (конкретными тренировками).

**Маршруты:**
- `GET /sessions` — история тренировок
- `POST /sessions` — начать тренировку
- `PATCH /sessions/:id/finish` — завершить тренировку
- `DELETE /sessions/:id` — удалить тренировку

---

## Что такое сессия

Сессия — это конкретная тренировка: "тренировался 12 мая, план Сплит 3 дня, день А". Одна сессия содержит много подходов (set_logs). Сессия создаётся когда пользователь нажимает "Начать тренировку" и завершается когда нажимает "Закончить".

`finished_at = NULL` означает что тренировка ещё идёт.

```go
package sessions

import (
	"time"

	"github.com/google/uuid"
	"gorm.io/gorm"
)

// WorkoutSession — конкретная тренировка пользователя.
// PlanID и DayID — указатели (*uuid.UUID) потому что могут быть nil
// (тренировка без плана — свободная тренировка).
// Указатель в Go означает "это значение может отсутствовать".
type WorkoutSession struct {
	ID         uuid.UUID      `gorm:"type:uuid;default:gen_random_uuid();primaryKey" json:"id"`
	UserID     uuid.UUID      `gorm:"type:uuid;not null"                             json:"user_id"`
	PlanID     *uuid.UUID     `gorm:"type:uuid"                                      json:"plan_id,omitempty"`
	DayID      *uuid.UUID     `gorm:"type:uuid"                                      json:"day_id,omitempty"`
	StartedAt  time.Time      `gorm:"not null"                                       json:"started_at"`
	FinishedAt *time.Time     `                                                      json:"finished_at,omitempty"`
	CreatedAt  time.Time      `                                                      json:"created_at"`
	UpdatedAt  time.Time      `                                                      json:"updated_at"`
	DeletedAt  gorm.DeletedAt `gorm:"index"                                          json:"deleted_at,omitempty"`
}
```

- [ ] **Шаг 2: Создать `internal/sessions/service.go`**

```go
package sessions

import (
	"time"

	"github.com/google/uuid"
	"gorm.io/gorm"
)

type Service struct{ db *gorm.DB }

func NewService(db *gorm.DB) *Service { return &Service{db: db} }

// List возвращает историю тренировок пользователя, от новых к старым.
func (s *Service) List(userID uuid.UUID) ([]WorkoutSession, error) {
	var sessions []WorkoutSession
	result := s.db.Where("user_id = ?", userID).Order("started_at DESC").Find(&sessions)
	return sessions, result.Error
}

// Create создаёт новую сессию (начало тренировки).
func (s *Service) Create(userID uuid.UUID, sess WorkoutSession) (WorkoutSession, error) {
	sess.UserID = userID
	result := s.db.Create(&sess)
	return sess, result.Error
}

// Finish устанавливает finished_at = NOW() (завершение тренировки).
func (s *Service) Finish(id, userID uuid.UUID) error {
	now := time.Now()
	// db.Model(...).Where(...).Update(...) — UPDATE workout_sessions SET finished_at = ? WHERE ...
	result := s.db.Model(&WorkoutSession{}).
		Where("id = ? AND user_id = ?", id, userID).
		Update("finished_at", now)
	return result.Error
}

// Delete мягко удаляет сессию.
func (s *Service) Delete(id, userID uuid.UUID) error {
	result := s.db.Where("id = ? AND user_id = ?", id, userID).Delete(&WorkoutSession{})
	return result.Error
}
```

- [ ] **Шаг 3: Создать `internal/sessions/handler.go`**

```go
package sessions

import (
	"encoding/json"
	"net/http"

	"github.com/go-chi/chi/v5"
	"github.com/google/uuid"
	"github.com/satanlittlehelper/knurl/backend/internal/auth"
)

type Handler struct{ svc *Service }

func NewHandler(svc *Service) *Handler { return &Handler{svc: svc} }

func (h *Handler) List(w http.ResponseWriter, r *http.Request) {
	userID, _ := auth.UserIDFromCtx(r.Context())
	sessions, err := h.svc.List(userID)
	if err != nil {
		http.Error(w, "internal error", http.StatusInternalServerError)
		return
	}
	w.Header().Set("Content-Type", "application/json")
	json.NewEncoder(w).Encode(sessions)
}

func (h *Handler) Create(w http.ResponseWriter, r *http.Request) {
	userID, _ := auth.UserIDFromCtx(r.Context())
	var body WorkoutSession
	if err := json.NewDecoder(r.Body).Decode(&body); err != nil {
		http.Error(w, "bad request", http.StatusBadRequest)
		return
	}
	sess, err := h.svc.Create(userID, body)
	if err != nil {
		http.Error(w, "internal error", http.StatusInternalServerError)
		return
	}
	w.Header().Set("Content-Type", "application/json")
	w.WriteHeader(http.StatusCreated)
	json.NewEncoder(w).Encode(sess)
}

func (h *Handler) Finish(w http.ResponseWriter, r *http.Request) {
	userID, _ := auth.UserIDFromCtx(r.Context())
	id, err := uuid.Parse(chi.URLParam(r, "id"))
	if err != nil {
		http.Error(w, "invalid id", http.StatusBadRequest)
		return
	}
	if err := h.svc.Finish(id, userID); err != nil {
		http.Error(w, "internal error", http.StatusInternalServerError)
		return
	}
	w.WriteHeader(http.StatusNoContent)
}

func (h *Handler) Delete(w http.ResponseWriter, r *http.Request) {
	userID, _ := auth.UserIDFromCtx(r.Context())
	id, err := uuid.Parse(chi.URLParam(r, "id"))
	if err != nil {
		http.Error(w, "invalid id", http.StatusBadRequest)
		return
	}
	if err := h.svc.Delete(id, userID); err != nil {
		http.Error(w, "internal error", http.StatusInternalServerError)
		return
	}
	w.WriteHeader(http.StatusNoContent)
}
```

- [ ] **Шаг 4: Подключить маршруты сессий в `cmd/api/main.go`**

Добавить импорт `"github.com/satanlittlehelper/knurl/backend/internal/sessions"` и внутри защищённой группы:

```go
sessionSvc := sessions.NewService(database)
sessionHandler := sessions.NewHandler(sessionSvc)

r.Get("/sessions", sessionHandler.List)
r.Post("/sessions", sessionHandler.Create)
r.Patch("/sessions/{id}/finish", sessionHandler.Finish)
r.Delete("/sessions/{id}", sessionHandler.Delete)
```

- [ ] **Шаг 5: Начать тренировку**

```bash
curl -s -X POST http://localhost:8080/sessions \
  -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" \
  -d "{\"plan_id\":\"$PLAN_ID\",\"day_id\":\"$DAY_ID\",\"started_at\":\"$(date -u +%Y-%m-%dT%H:%M:%SZ)\"}" | jq .
```

Сохранить `id` из ответа в `SESSION_ID`. Поле `finished_at` должно быть `null`.
