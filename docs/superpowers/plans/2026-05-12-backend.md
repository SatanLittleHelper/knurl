# План реализации бэкенда Knurl — Индекс

**Цель:** Go REST API для Knurl — авторизация, кэш упражнений, планы тренировок, сессии, подходы, офлайн-синхронизация.

**Стек:** Go 1.22, Chi router, GORM (ORM), PostgreSQL, goose (миграции), golang-jwt/jwt, bcrypt, godotenv
