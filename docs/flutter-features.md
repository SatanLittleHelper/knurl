# Flutter-приложение Knurl — Список фич

Разбивка на фичи для последовательной разработки и брейнштормов.
Дизайн-документ: `docs/superpowers/specs/2026-05-12-knurl-design.md`

## Порядок реализации

### Инфраструктура
1. [x] **Проект Flutter** — инициализация, структура папок, зависимости (drift, dio, riverpod/bloc, go_router)
2. [ ] **Локальная БД (SQLite/drift)** — схема таблиц (Exercise, WorkoutPlan, WorkoutDay, WorkoutSession, SetLog), миграции
3. [ ] **API-клиент** — HTTP-клиент для Go-бэкенда, обработка ошибок, interceptors для JWT

### Экраны
4. [ ] **Auth** — регистрация и вход (email + пароль), хранение и обновление JWT
5. [ ] **Home** — тренировка на сегодня (из плана) + последние 3 сессии
6. [ ] **Planner** — список планов, создание/редактирование плана с упражнениями и целевыми весами
7. [ ] **Active Workout** — активная тренировка: подходы с весом/повторениями, таймер отдыха, добавление упражнений вне плана
8. [ ] **History** — список прошлых сессий по дате, детали сессии
9. [ ] **Exercise Library** — библиотека упражнений из внешнего API, кэш в SQLite, фильтр по мышцам

### Фоновые сервисы
10. [ ] **Sync Engine** — фоновая синхронизация записей с `synced = false` на Go-сервер, получение изменений с других устройств
